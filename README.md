# Letter Classification Restricted Boltzmann Machine

Pytorch implementation of the Paper [Conditional Restricted Boltzmann Machines for Structured Output Prediction](https://arxiv.org/abs/1202.3748) employed on a Handwritten letter classification Task

The dataset I used was taken from kaggle: [English Handwritten Characters](https://www.kaggle.com/datasets/dhruvildave/english-handwritten-characters-dataset)

References:
- [Restricted Boltzmann Machines: Introduction and Review](https://arxiv.org/abs/1806.07066)
- [Restricted Botzmann Machine: Derivations](https://ofai.at/papers/oefai-tr-2014-13.pdf)
